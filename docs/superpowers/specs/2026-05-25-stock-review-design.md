# AI 股票复盘系统 — 设计文档

## 目标

每日收盘后自动生成覆盖 10 个维度的市场复盘报告，替代用户手动查数据的 30 分钟。

## 架构

```
AkShare(数据源) → Python FastAPI(后端) → Next.js(前端)
                      ↓
                  DeepSeek API(AI 分析)
```

**为什么 Python 做后端**：AkShare/pandas/numpy 是 Python 生态，无法用 Next.js 替代。

## 数据流

```
收盘后触发 → Python 拉取 AkShare 数据 → pandas 清洗+计算基准
→ DeepSeek 生成 AI 分析文本 → 存入 JSON → Next.js 前端读取展示
```

## 三个技术组件

### A. Python 数据引擎
- AkShare 拉取：指数、板块、涨停板、北向、龙虎榜、个股 K 线
- pandas 计算：量价关系、涨跌比、赚钱效应、资金分层、基准对比
- 输出：`data/{date}/` 目录下的结构化 JSON + CSV

### B. AI 分析层
- 读 data/*.json → 调用 DeepSeek API → 生成 10 个区的文字分析
- 情绪周期量化判断：7 指标 + 历史分位数
- 板块持续性评分：3 日/5 日滚动窗口排名
- 输出：`data/{date}/report.json`（前端直接消费）

### C. 前端仪表盘
- Next.js 页面展示当日报告
- ECharts 可视化
- 简单的时间线，一个页面就能看完

## MVP 范围

**第一批实现（2-3 天）**：
- 数据拉取脚本（收盘后手动运行一次）
- AI 分析生成（读取数据 → 生成报告）
- 一个 Next.js 页面展示当日报告

**暂不实现**：
- 盘中实时数据
- 定时自动运行
- 历史回测
- 用户系统

## 10 区报告结构

| 区 | 内容 | AI 自动化 |
|----|------|----------|
| A 宏观环境 | 美股/VIX/汇率/商品/融资余额 | 100% |
| B 竞价开盘 | 竞价方向/开盘攻击/昨日溢价 | 100% |
| C 个人操作 | 用户自己填 | 30% |
| D 市场全景 | 量价/宽度/赚亏效应/涨停结构 | 100% |
| E 资金流向 | 北向/主力游资散户/大单/龙虎榜 | 90% |
| F 板块分析 | 强度排行/轮动/量价验证/持续性 | 80% |
| G 热点联动 | 新闻→板块→龙头 | 90% |
| H 个股筛选 | 主线归属/启动位/量能/封单 | 70% |
| I 情绪周期 | 7 指标 + 分位数 | 100% |
| J 明日预案 | 场景推演 + 观测点 | 40% |
